# Hourbell 500 점검표

16비트 JRPG로서 완성도와 레벨 깊이를 갖추기 위해 확인할 500개 항목입니다.
10개 분야 × 50개, 각 항목은 v0.2 코드를 직접 읽고 판정했습니다.

| 표시 | 뜻 |
|---|---|
| ✅ | 이미 충족 (v0.1부터) |
| ⬆ | 이번 1차 업그레이드(v0.2)에서 충족 |
| 🟡 | 일부만 충족 |
| ❌ | 미충족 (다음 단계 후보) |
