# 소프트락 점검표

진행이 막히지 않으려면 장마다 아래 플래그가 차례로 켜져야 합니다. 플래그는 세이브의 `flags`에 남습니다.
`node tests/smoke.mjs`가 1장부터 크레딧까지 이 순서를 실제 게임으로 밟으며 확인합니다(각 장 제목 옆 괄호가 그 장을 확인하는 smoke 단계).
새 장이나 새 길막이를 넣을 때 이 표와 smoke를 함께 고칩니다.

## 길을 막는 곳

모든 길막이는 이전 장을 마친 플래그(`chapterN`, 종지기에게 조각을 전하면 켜짐)만 봅니다.

| 지도 | 막힌 길 | 열리는 조건 | 다시 닫히는 조건 |
|---|---|---|---|
| 울림골 | 동쪽 → 물안개 길 | `chapter1` | - |
| 울림골 | 북쪽 → 메아리 협곡 | `chapter2` | - |
| 울림골 시계탑 | → 50년 전 울림골 | `chapter3` | `chapter6` (그 뒤로는 아워벨 내부로) |
| 울림골 시계탑 | → 아워벨 내부 | `chapter6` | - |
| 메아리 협곡 | 북쪽 → 눈꽃 고갯길 | `chapter4` | - |
| 눈꽃 산마루 | 북쪽 → 구름다리 | `chapter5` | - |
| 50년 전 울림골 시계탑 | → 현재 울림골 | 항상 | - |

## 막히지 않게 하는 장치

- 전투에서 지면 HP를 채우고 그 장에서 마지막으로 쉰 여관(없으면 울림골)에서 깨어납니다. 골드는 절반만 잃고 진행 플래그는 그대로입니다 (src/battle.js lose).
- 여관은 언제나 공짜로 쉴 수 있습니다. 약초가 떨어져도 회복할 수 있습니다.
- 보스는 제단에서 몇 번이고 다시 도전할 수 있고, 다시 도전하면 소개 대사가 한 줄로 줄어듭니다.
- 조각을 얻으면 종소리를 따라 울림골로 바로 돌아갈 수 있습니다(거절하면 걸어서 돌아가면 됩니다).
- 과거(4장)에서 현재로 돌아오는 시계탑은 언제나 열려 있습니다.
- 동료는 진행에 필수가 아닙니다(밸런스 테스트 '새 동료 없이도').
- 게임 루프는 오류가 나도 멈추지 않고, 자동 저장은 대화·전투·메뉴·화면 전환 중에는 하지 않습니다.
- 기록이 망가지면 직전 기록 백업에서 불러옵니다.
