# Hourbell 기획서 (v1.2 기준)

처음 기획(v0.1)의 방향(1~4절)은 그대로이고, 5~7절은 지금 게임의 실제 구성, 8절부터는 만드는 규칙입니다. 바뀐 점은 [CHANGELOG.md](../CHANGELOG.md)에 있습니다.

## 1. 한 줄 정의

마을에 들어서면 음악 때문에 멈춰 서게 되는, 분위기가 주인공인 16비트풍 JRPG.

**핵심 재미:** 멈춘 세계에 종소리를 한 소절씩 되돌려, 음악과 풍경이 다시 움직이는 걸 보는 것.
새 기능은 이 질문으로 거릅니다. "이게 음악이나 풍경이 살아나는 순간을 더 또렷하게 하는가?" 아니라면 미루거나 빼고, PR 템플릿에도 이 한 줄을 적습니다.

## 2. 계승하려는 것

| 그 시절 게임에서 남은 것 | Hourbell에서의 구현 |
|---|---|
| 흥얼거릴 수 있는 선율 | 지역별 주제 선율(라이트모티프)과 상황별 편곡 |
| 그 시대 최고 수준의 도트 | 제한된 팔레트 안에서 애니메이션 프레임과 배경 연출에 집중 |
| 끊김 없는 모험 | 필드에서 바로 이어지는 전투, 짧은 전환 연출 |
| 누구나 끝까지 가는 따뜻함 | 단순한 메뉴, 친절한 난이도, 개성 있는 마을 사람 대사 |

## 3. 음악 설계

- **주제 선율 1개 = 지역 1곳.** 같은 선율을 다음처럼 변주합니다.
  - 마을: 느린 템포, 부드러운 음색
  - 필드: 템포를 올리고 베이스와 리듬 추가
  - 전투: 단조 또는 빠른 아르페지오로 긴장감
  - 조각 획득: 그 지역 선율의 빈 소절이 채워짐
- 장면 전환 시 끊지 않고 **페이드와 박자 맞춤 전환**을 우선합니다.
- 프로토타입은 Web Audio로 실시간 합성(칩튠 계열)하여 외부 음원 없이 시작합니다.

## 4. 그래픽 설계

- 내부 해상도 480x270. PC와 태블릿은 정수 배율로 확대(픽셀 선명도 유지), 휴대폰은 터치 버튼 자리를 뺀 공간에 맞춰 확대.
- 지역마다 팔레트 1세트. 시간대(아침, 노을, 밤)는 팔레트 보정으로 표현.
- 배경 애니메이션 우선순위: 물결 > 나뭇잎 > 빛 번짐 > 연기.
- 도트 규칙
  - 타일 16x16. 사람은 16x16 격자 한 장에 그리고(src/sprites.js), 색만 바꿔 여러 인물로 씀.
  - 외곽선은 검정이 아니라 짙은 보라 `#1a1424`. 눈은 `#20162e`.
  - 빛은 왼쪽 위에서 옴: 밝은 면은 위·왼쪽, 그림자는 오른쪽 아래.
  - 보스는 같은 격자를 크게 키우지 않고 더 큰 원본으로 그림.
  - 모든 그림은 코드로 그리고, 외부 이미지는 쓰지 않음.

## 5. 구성 (v1.0부터)

| 장 | 지역 | 보스 | 권장 레벨 | 새 동료 |
|---|---|---|---|---|
| 1 | 울림골, 바람결 들판, 비밀 풍경 숲 | 침묵의 파수꾼 | 4 | 미오(여관 노래꾼, 서브 퀘스트) |
| 2 | 물안개 길, 물안개 항구 | 안개삼킴이 | 6 | |
| 3 | 메아리 협곡, 울림 광산 | 메아리왕 | 9 | 단비 |
| 4 | 50년 전 울림골, 째깍 숲 (시계탑으로 과거) | 시간갉기 | 12 | 하루 |
| 5 | 눈꽃 고갯길, 눈꽃 산마루 | 서리날개 | 15 | |
| 6 | 구름다리, 별빛 천문대 | 일식 | 18 | |
| 7 | 아워벨 내부 (시계탑으로 종 안) | 정적 | 21 | |

- 장마다 여관, 상점, 장비 7칸 세트, 서브 퀘스트 하나. 조각을 얻으면 종지기에게 돌아가 장 카드를 보고 다음 장이 열림
- 전투: 속도 순 행동, 소리·바람 약점과 내성. 보스는 파동(방어로 절반), 안개(평범한 공격 반감), 정적(기술 봉인)을 쓰고, 셋 다 행동을 고르기 전에 예고
- 플레이 시간: 장마다 약 20~30분

## 6. 밸런스 규칙

`tests/chapterspec.mjs`(장별 기준)와 `tests/chapters.test.mjs`, `tests/rules.test.mjs`가 시뮬레이션으로 지킵니다.

- 보스의 권장 레벨은 그 장 장비를 다 갖췄을 때 기준. 레벨로 장비를 대신할 수 있다(장비가 덜하면 1~2레벨 더)
- 자동 전투가 아닌 사람도 이긴다: 공격과 약초만으로 권장 레벨, 도구 없이 공격만으로 권장 +2레벨(1장만 바람 약점을 익히는 보스라 공격만은 Lv7)
- 가장 최근에 합류한 동료는 도움이 되지만 필수가 아님
- 그 장에 막 도착한 레벨로도 길의 필드 전투가 공정하고, 필드에서 번 골드로 장비 일부를 살 수 있음
- 레벨업은 필드를 몇 바퀴 도는 정도(자동 사냥 기준), 노가다가 되지 않음

## 7. 기술 구성

- 순수 HTML + JavaScript (Canvas 2D, Web Audio). 빌드 도구 없음. 그림과 음악은 모두 코드로 생성, 외부 에셋은 Galmuri 글꼴의 서브셋뿐
- `src/`: `core.js`(루프, 입력, 화면) → `rules.js`(규칙, 수치, 세이브) → 화면별 파일(`world.js`, `battle.js`, `menu.js` ...) → 장별 데이터(`ch2.js`~`ch7.js`, 공통 틀은 `chapter.js`)
- 기록: 브라우저 저장소에 저장하고 직전 기록 하나를 백업, 세이브 코드로 기기 간 이동
- 테스트: Node 기본 테스트(규칙, 밸런스, 맵 데이터)와 헤드리스 Chrome(`tests/smoke.mjs` 처음부터 엔딩까지, `tests/layout.mjs` 화면 배치). 사용법은 README
- 배포: main에 머지하면 Vercel이 https://hourbell.vercel.app 에 자동 배포

## 8. 장마다 플레이어가 느낄 것 (마일스톤)

장을 만들 때 기능 목록보다 이 한 줄을 먼저 정하고, 다 만든 뒤 이 느낌이 나는지로 끝을 판단합니다.

| 장 | 느낄 것 |
|---|---|
| 1 | 낯선 바람 속에서 첫 소절을 찾아 마을에 처음 종소리가 울리는 순간 |
| 2 | 안개가 걷히고 항구에 배와 뱃노래가 돌아오는 안도 |
| 3 | 겹겹이 울리던 메아리가 하나로 잦아드는 고요 |
| 4 | 젊은 종지기와 만나고 헤어지며 시간이 이어져 있음을 느끼는 먹먹함 |
| 5 | 눈보라 끝에 맑게 울리는 얼음 종의 청량함 |
| 6 | 멈춘 별들이 다시 도는 밤하늘의 경이 |
| 7 | 일곱 소절이 하나가 되고 울림골에 처음 밤이 오는 마무리 |

## 9. 하지 않을 것

범위를 지키려고 미리 정해 둔 것입니다. 바꾸려면 여기부터 고칩니다.

- 온라인 기능(계정, 랭킹, 멀티플레이). 저장은 브라우저와 세이브 코드로 충분
- 분기 엔딩과 큰 선택지. 이야기는 하나로 곧게 가고, 선택의 흔적은 작게(크레딧 한 줄 등) 남김
- 외부 그림·음원 에셋. 모든 그림과 음악은 코드로 만듦
- 빌드 도구와 프레임워크. 순수 HTML과 JavaScript 그대로
- 과금, 광고, 수집 뽑기
- 복잡한 성장 시스템(스킬 트리, 직업 전환). 레벨·장비·동료 장신구까지만

| 시점 | 바꾼 것 | 이유 |

## 11. 레퍼런스와 배울 점

에셋이나 곡은 가져오지 않고, 만드는 태도만 배웁니다.

- 크로노 트리거: 시간 여행으로 같은 마을을 다른 시대에 다시 걷게 하는 구조. 4장의 50년 전 울림골
- MOTHER 2: 작은 마을 사람들의 짧고 따뜻한 대사가 세계를 살아 있게 함. 장마다 바뀌는 마을 대사
- 성검전설 2: 필드에서 끊기지 않고 이어지는 전투와 계절·지역마다 바뀌는 음악
